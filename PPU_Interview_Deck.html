① DiscoverThree insights that shaped everything after
Self-imposed posting cap
Sellers stop posting when packages run out because spending more feels like a loss. PPU must make unlimited posting feel safe, not just fair.
Vertical user muscle memory
Migrating sellers expect PPU as standard. Familiarity is a feature — over-engineering the flow is the real risk in the migration window.
Discount confusion destroys trust
All 10 participants noticed discount offers but couldn't explain what triggered them. Darko (ethics agent) flagged a potential dark pattern — discounts cut from MVP scope.

③ DevelopThe concept — and the catch that saved a sprint
Concept selected

Postpaid PPU · bracket pricing + benefit tiers

Sellers pick a quality tier (Basic / Premium / Mega), post unlimited ads, and are billed at month-end on incremental brackets. A progress-to-next-bracket mechanic turns billing transparency into a posting incentive. No expiry, no upfront commitment.

Key ethical catch — Darko

Auto-extend disclosure flagged before dev

Darko identified that auto-extended ads under variable pricing required explicit labelling under B2B rules (GDPR / P2B). Added to scope before it became a launch blocker — an agent catch that saved a full sprint cycle.
